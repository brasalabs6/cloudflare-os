# Computers Gatekeeper — plan.md

> **Estado:** PLANEJADO, não implementado por estes documentos. **Origem:** U-006/U-007 no [registro de inputs](../../docs/architecture/USER_INPUT_LEDGER.md). **Arquitetura:** [Unified v2](../../docs/architecture/AGENT_PLATFORM_UNIFIED_V2.md).

## Escopo e dependências

Computer capabilities are separate from CodingAgent capabilities. Arbitrary PTY and shell require higher privilege than a prompt/tool approval. File read observations are bounded and root-safe; writing/exec/export actions honor Gatekeeper submit/apply. Ticket bound to principal origin session generation, single use and ≤60s.

**Fonte de destilação:** Grokbot PTY/tmux terminal, file browser, signed permits; cloudflare-os PR#2 terminal/error UX; current Gatekeeper authoring guide.

**Outras dependências:** `agent-protocol` ACC v1, existing Workshop/Overseer/Gatekeeper permissions, `agent-control-plane` Task/Agent definitions, `agent-loop` (when scheduled), runtime DO vs native Overseer and immutable release registry. Do not overwrite already-implemented systems.
