> **Estado:** PLANEJADO, não implementado por estes documentos. **Origem:** U-006/U-007 no [registro de inputs](../../docs/architecture/USER_INPUT_LEDGER.md). **Arquitetura:** [Unified v2](../../docs/architecture/AGENT_PLATFORM_UNIFIED_V2.md).

## Escopo e dependências

Extend beyond coding sessions to AgentDefinitions, Tasks, trigger inspection and bounded agent/child work, but never mix human direct execution with Gadget deferred actions. Draft capability surface requires explicit operator API review BEFORE implementing worker internals; only submitted action appears simulated pending until approved applyAction. Observations call authorizeObservation.

**Fonte de destilação:** Existing .agents/skills/write-gatekeeper/SKILL.md, gatekeeper-kit, workshop-shared gatekeeper.ts, AgentSpawnerConfig; Grokbot authorization reference.

**Outras dependências:** `agent-protocol` ACC v1, existing Workshop/Overseer/Gatekeeper permissions, `agent-control-plane` Task/Agent definitions, `agent-loop` (when scheduled), runtime DO vs native Overseer and immutable release registry. Do not overwrite already-implemented systems.
